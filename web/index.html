Setup.
Use this web interface from your phone or laptop. The Pi handles Bluetooth and stores scan history.

  
AI diagnosis & web research
Research uses OpenAI's Responses API with web search. It needs your own API key and incurs API charges. An active job is limited to one scan at a time.
Keys entered here stay in server memory until restart. For persistence, copy .env.example to .env and set OPENAI_API_KEY. Your key is never returned by the server.
What leaves the Pi
When research runs, vehicle context, codes, selected snapshot readings, symptoms and matching reference descriptions are sent to OpenAI for web research. VIN, Bluetooth addresses, scan history and raw frames stay local. Internet research uses the provider's HTTPS connection; this website remains HTTP.

  
Connection checklist
  1. In Adapter & vehicle, select the Pi Bluetooth radio and turn it on.
  2. Plug in the Carista EVO and turn the vehicle ignition on.
  3. Close Carista and any other app connected to the adapter.
  4. Discover receivers and identify yours by its name, address and signal. Pair it if required, answer any PIN or confirmation here, then connect and initialize diagnostics.
  5. Carista EVO uses Bluetooth LE. Other receivers need compatible BLE UART services, or a serial port already exposed to the Pi.
  6. Enter exact vehicle context, scan, then choose live readings.
Browser access
The Pi owner supplies the web address and account details. Bluetooth discovery, pairing and PIN entry are handled on this page; users do not need the Pi desktop or SSH.
Local storage
Scans and up to 10,000 live polling cycles per scan are stored in proactive.sqlite3 in the configured data directory. JSON exports include the latest 200 saved cycles. Back up the data directory with ProActive stopped.
Known limits
An ELM-compatible adapter does not supply unpublished code definitions, OEM gateway credentials or manufacturer software. Adapter and vehicle compatibility must be verified on your hardware.
