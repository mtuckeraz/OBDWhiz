# Hardware compatibility

| Hardware | Evidence |
| --- | --- |
| Raspberry Pi 4 / BlueZ | Prior deployment verified running service and radio discovery. Carista was intermittently visible and a full vehicle scan remained unverified in that deployment. |
| Carista EVO / Windows BLE | Prior Windows testing recorded standard scans and live polling on one vehicle. |
| Raspberry Pi 5, dedicated battery monitors | Untested in this milestone. |
| Generic ELM-compatible serial or BLE | Existing transport available. Coverage depends on adapter and vehicle. |

Vehicle dossiers work without an adapter. Phase 1 does not change scanner communications.
